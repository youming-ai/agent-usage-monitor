# Notify Watcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 1-second `tokio::time::interval` polling in the TUI reader task with `notify` FS events + 50ms debounce per platform + 30s fallback poll. Quota fetch (HTTP) is unchanged.

**Architecture:** New `src/watcher.rs` module wraps `notify` + `notify-debouncer-full` to produce `WatcherMessage` events. The `UsageSource` trait gets a new `get_watch_directories()` method (default empty). Each of the 13 readers implements it (JSONL: parent dir recursive; SQLite: file's parent dir non-recursive). `main.rs` replaces its `interval(1s)` loop with a `tokio::select!` over the watcher channel + a 30s fallback interval.

**Tech Stack:** `notify 8` (cross-platform FS events: FSEvents/inotify/ReadDirectoryChangesW), `notify-debouncer-full 0.6` (debouncer wrapper), `tokio` (existing), `std::sync::mpsc` → `tokio::sync::mpsc` for async integration. **No other new dependencies.**

## Global Constraints

- New `Cargo.toml` dependencies: `notify = "8"`, `notify-debouncer-full = "0.6"`. Nothing else.
- `AppState`, `PlatformState`, `UsageRecord`, `UsageSource::scan_all`/`poll_delta` MUST NOT change semantics.
- `UsageSource::get_watch_directories()` is a new method with a default `vec![]` impl (backward-compatible).
- The 1s `tokio::time::interval` polling task in `main.rs` MUST be removed (replaced by watcher + 30s fallback). No dual-source race.
- Quota fetch (HTTP, 2-min interval) is **out of scope** — unchanged.
- 30s fallback poll IS the safety net for FS event loss; spec-mandated.
- 50ms per-platform debounce IS the spec-mandated value; not parameterized.
- Cross-platform: macOS FSEvents / Linux inotify / Windows ReadDirectoryChangesW via `notify`'s `RecommendedWatcher`.
- No TUI restructuring; only the reader task's polling mechanism changes.
- All existing tests must still pass.

```rust
pub fn start_watchers(
    paths: &AgentPaths,
) -> (Vec<PlatformWatcher>, mpsc::Receiver<WatcherMessage>) {
    let (tx, rx) = mpsc::channel::<WatcherMessage>(64);
    let mut watchers = Vec::with_capacity(13);

    for entry in platforms::entries() {
        let path = paths.path_for(entry.tab);
        if !path.exists() {
            continue; // skip unavailable platforms
        }
        let mut reader = entry.build_reader(path.clone());
        let watch_dirs = reader.get_watch_directories();
        if watch_dirs.is_empty() {
            continue; // reader has no watch directories
        }

        // SQLite readers: watch the parent dir of the .db file.
        // JSONL readers: watch the data dir recursively.
        let is_sqlite = matches!(entry.tab, Tab::OpenCode | Tab::Hermes | Tab::MimoCode);
        let tx = tx.clone();
        let platform = entry.platform;

        let mut debouncer = new_debouncer(
            Duration::from_millis(50),
            None,
            move |res: DebounceEventResult| {
                if let Ok(events) = res {
                    for event in events {
                        for path in &event.paths {
                            // Best-effort: if channel is closed, drop event.
                            let _ = tx.blocking_send(WatcherMessage::Event {
                                platform,
                                path: path.clone(),
                            });
                        }
                    }
                }
            },
        )
        .expect("create debouncer");

        for dir in &watch_dirs {
            let watch_path = if is_sqlite && dir.is_file() {
                dir.parent().unwrap_or(dir).to_path_buf()
            } else {
                dir.clone()
            };
            debouncer
                .watcher()
                .watch(&watch_path, RecursiveMode::Recursive)
                .expect("watch path");
        }

        watchers.push(PlatformWatcher { platform, _debouncer: debouncer });
    }

    (watchers, rx)
}
```

```rust
// FS-driven reader task: watch + 30s fallback.
let (_platform_watchers, mut watcher_rx) =
    watcher::start_watchers(&agent_paths);
let mut fallback = tokio::time::interval(Duration::from_secs(30));
fallback.tick().await; // discard immediate first tick

loop {
    tokio::select! {
        Some(msg) = watcher_rx.recv() => {
            let platform_filter: Option<crate::state::Platform> = match &msg {
                WatcherMessage::Event { platform, .. } => Some(*platform),
                WatcherMessage::FallbackTick => None, // sweep all
            };
            for entry in platforms::entries() {
                if let Some(p) = platform_filter {
                    if entry.platform != p { continue; }
                }
                let path = agent_paths.path_for(entry.tab);
                if !path.exists() { continue; }
                let mut reader = entry.build_reader(path);
                let platform = entry.platform;
                let app_state = app_state.clone();
                task::spawn_blocking(move || {
                    for record in reader.poll_delta() {
                        if let Err(e) = app_state.add_record(platform, record) {
                            warn!("add_record failed: {e}");
                        }
                    }
                });
            }
        }
        _ = fallback.tick() => {
            // Same as FallbackTick: sweep all platforms.
            for entry in platforms::entries() {
                let path = agent_paths.path_for(entry.tab);
                if !path.exists() { continue; }
                let mut reader = entry.build_reader(path);
                let platform = entry.platform;
                let app_state = app_state.clone();
                task::spawn_blocking(move || {

                        if let Err(e) = app_state.add_record(platform, record) {
                            warn!("add_record failed: {e}");
                        }
                    }
                });
            }
        }
    }
```

```markdown
## Real-time updates

The TUI uses `notify` (FSEvents on macOS, inotify on Linux, ReadDirectoryChangesW
on Windows) to react to file changes immediately, instead of polling on a timer.
A 50 ms per-platform debounce coalesces bursts of writes; a 30 s fallback poll
ensures the display stays current even if a FS event is dropped.

Network filesystems (NFS, SMB) are not officially supported by `notify`; on those
paths the 30 s fallback still works.
```
